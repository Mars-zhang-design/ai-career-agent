# Python 后端项目能力参考
这是依据 FastAPI 教程主题整理的能力参考，不是招聘样本，不包含薪资、学历、工作地点或年限承诺。

## 服务开发
FastAPI 教程涵盖请求体、参数校验、响应模型、依赖注入、安全、SQL 数据库及测试。练习时应能解释请求如何进入处理函数，以及响应字段如何受到模型约束。

## 项目证据建议
作者建议用受保护的资料读取接口展示身份校验，用非法输入和越权访问测试说明边界。项目完成情况必须来自实际实现，不能由技能列表推定。
