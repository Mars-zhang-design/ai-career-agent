# Python 官方教程学习路线
Python 官方教程包含控制流、数据结构、模块、输入输出、异常以及类等主题。教程面向已有编程基础但刚接触 Python 的读者。

## 作者建议的练习
先完成一个 UTF-8 文本读取器，处理空文件和读取错误；再把文本按路径组织成列表，为每项生成确定的标识。最后用模块和命令行入口封装，记录输入与输出示例。
验收建议：重复运行得到一致结果；不存在的路径有明确提示；遇到无效输入时不破坏已有文件。
本路线是自学建议，没有就业、薪资或学习时长保证。
