# 自动化测试练习
Python 标准库 unittest 提供测试用例、测试夹具、测试套件和测试运行器。可以通过测试发现命令收集并运行测试文件。

## 作者建议的验收任务
为知识库分别测试正常导入、元数据缺失、空目录、重复构建和文档更新。模型调用可使用测试替身，但需要另做真实持久化及真实模型检索检查。
用临时目录隔离测试数据。不要让回归测试连接真实业务数据库或付费模型。
测试替身通过只能说明程序流程满足断言，不能证明真实检索质量或模型生成质量。
